# Employee Data Dashboard

## 1. Project Description
The Employee Data Dashboard is a data analysis web application developed using Python, Streamlit, and Pandas. It allows users to view, search, filter, and analyze employee information through an interactive dashboard.

## 2. Project Objectives
- To display employee data in an organized format.
- To perform basic data analysis.
- To provide interactive search functionality.
- To visualize employee information using charts.
- To create a user-friendly data dashboard.

## 3. Dataset
This project uses an employee dataset stored in a CSV file named `Employee.csv`.

The dataset is loaded using the Pandas library.

## 4. Tools and Technologies Used
- **Python:** Main programming language.
- **Visual Studio Code:** Code editor.
- **Streamlit:** Used to create the interactive web application.
- **Pandas:** Used for reading, handling, and analyzing data.
- **GitHub:** Used to store and share project source code.

## 5. Libraries Used
- Streamlit
- Pandas

## 6. Project Features
- Interactive Employee Search
- Column Selection
- Employee Data Table
- Total Employees Summary
- Displayed Records Summary
- Bar Chart Visualization
- Black and Dark Theme Interface

## 7. Data Analysis
The application displays employee records in a table and provides a chart based on the selected column.

Users can search employee records and select different columns for analysis.

## 8. Installation Requirements
Install Python and the required libraries.

Install the libraries using:

```bash
pip install -r requirements.txt
```

## 9. How to Run the Application
Open the project folder in Visual Studio Code.

Open the terminal and run:

```bash
python -m streamlit run lab_manual.py
```

The application will open in the web browser.

## 10. Project Files
- `lab_manual.py` – Main application source code.
- `Employee.csv` – Employee dataset.
- `requirements.txt` – Required Python libraries.
- `README.md` – Project description and instructions.

## 11. Conclusion
The Employee Data Dashboard was successfully developed using Python, Streamlit, and Pandas. It provides an interactive interface for searching, displaying, and analyzing employee data through tables and charts.
